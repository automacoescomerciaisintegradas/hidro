# HIDROREABILITAR - Landing Page

Landing page institucional da HIDROREABILITAR, desenvolvida com React, TypeScript e Vite.

## Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Requisitos

- Node.js 18+
- npm

## Executar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Preview local do build

```bash
npm run preview
```

## Estrutura principal

```text
src/
  components/
  pages/
  hooks/
  lib/
```
